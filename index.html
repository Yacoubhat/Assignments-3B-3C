Assignment Details

For the data visualisation website, it is expected that the visualisations will be programmed using D3. If the intended design cannot be achieved using D3 in the available time, other tools may be used, but they must be identified and justified in the submission. This assignment supports unit learning outcomes 1, 2, 3 and 4.

Website Requirements

The data visualisation website is a major part of this unit's assessment. The assessment considers the complexity of the website, its implementation, functionality, interactivity and visual presentation. The following table summarises the assessment levels.

Website criteria Needs improvement Good Very good
Complexity of project A very simple dataset is used or the project has a limited number of variables. A rich dataset is used. The user can interact with one or more variables to explore the dataset. Multiple datasets are used or datasets from different sources are combined in new ways. Some variables may be derived or specially calculated for use in the visualisation.
Implementation – Part 1
  • No functional website or visualisation
  • Little or no interactivity
  • Data does not display correctly
  • Interactivity depends on changing pages instead of programming the visualisation

The website is accessible and demonstrates suitable features such as:

  • Scalable labelled axes
  • Data import
  • Transitions
  • Zoom, filtering or brushing
  • Details on demand

The code is well formed and commented, external sources are acknowledged, and the visualisation includes supporting context.

As described under “Good”, plus:

  • Interactivity works as expected
  • Users can interact with variables to explore the dataset
  • The website responds well to the original data visualisation questions
  • Very good supporting context
  • The visualisations are largely programmed using D3
